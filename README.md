# PEP - Robotic Process Automation (RPA)

This repository contains UiPath Robotic Process Automation (RPA) projects, workflows, assignments, and practical exercises organized by day.

## 📂 Repository Structure

- **Day 1**: UiPath assignments (assign1 through assign10) & basic workflows (`Main.xaml`, project configs).
- **Day 2**: Conditional logic, date/string manipulation, and control flow workflows (`Grade.xaml`, `if_Date.xaml`, `if_File.xaml`, `if_Positive.xaml`, `if_String.xaml`, `Leapyear.xaml`, `Odd_Even.xaml`, etc.).
- **Day 3**: Iterations, loops, collections, and mathematical workflows (`fibonacci.xaml`, `fruits.xaml`, `guess.xaml`, `large_sum.xaml`, `random.xaml`, `reverse.xaml`, `sort.xaml`, `timer.xaml`, etc.).
- **Day 4**: String manipulation and data extraction (`Contains.xaml`, `Extract Numbers.xaml`, `Non-alphanumeric.xaml`, `Reverse.xaml`, `Singlesentence.xaml`, `Split.xaml`, `Substring.xaml`, `Uppercase.xaml`).
- **Day 5**: File and document management automation (`Document Management.xaml`, `Excel File.xaml`, `Filter_Files.xaml`, `Latestfile.xaml`, `Zip Files.xaml`, etc.).
- **Day 6**: PDF automation and data processing (`read pdf.xaml`, `merge pdf.xaml`, `join.xaml`, `count.xaml`).
- **Day 7**: Excel data manipulation, filtering, and report generation (`finance & salary.xaml`, `it & finance.xaml`, `read range.xaml`, `write cell.xaml`, `pdef1.xaml`, `fliter.xaml`).
